# Web Ucapan Ulang Tahun Komik Pink

Halaman ucapan selamat ulang tahun bertema pink bergaya komik warna dengan efek animasi balon, partikel love vektor, serta dukungan layar sentuh untuk HP.

## Fitur Utama

- Gaya komik warna dengan panel bertinta tegas, latar titik halftone, gelembung ucapan, dan efek tipografi komik.
- Animasi balon dan hati (love) berbasis Canvas 2D dan SVG tanpa satu pun karakter emoji.
- Interaksi langsung di HP maupun desktop: ketuk balon untuk meletuskan, sentuh layar untuk menebar love, serta ketuk kue untuk meniup lilin.
- Kustomisasi nama penerima, pengirim, dan pesan ucapan lewat tombol atur atau parameter URL (`?to=Nama&from=Pengirim&msg=Pesan`).
